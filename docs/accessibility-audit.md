Changes made during this audit: the standalone admin authentication page now has a `main` landmark; the admin editor dialog is explicitly named by its title; and keyboard-only regression coverage was added. The focused admin sign-in Playwright/axe test passed (1 test), the admin manager component suite passed (5 tests), and TypeScript typecheck passed.

Environment limitation: the Docker CLI is unavailable here, so MongoDB/MinIO-backed account, cart, and admin workflows could not be exercised end to end. The configured MB Way checkout is also disabled without provider credentials. The broad browser run timed out while waiting for the unauthenticated cart API; that is not evidence of an accessibility failure, but it prevents an all-pages axe pass claim.

To close SK-0181: start healthy local infrastructure and a seeded test account; enable a safe sandbox checkout; run the complete Playwright suite at desktop and mobile widths in English, Portuguese, and Persian; manually complete sign-in, order, and one authorized admin create/edit flow using only Tab, Shift+Tab, Enter, Space, arrow keys, and Escape; then record any focus/announcement findings and rerun axe with zero critical or serious violations.
