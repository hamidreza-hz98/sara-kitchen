# Public menu (SK-0167)

`/menu` is a Server Component backed by the public dish catalog service. It renders published dishes and categories in HTML before hydration. Category detail URLs reuse the same catalog presentation with category-specific breadcrumbs, banner, description, and SEO metadata. The root menu uses its static SEO record and structured data. Search and filter forms use native labelled controls and GET parameters; grid/list and pagination are ordinary URL links, so the view works without client JavaScript and can be shared or bookmarked.

The allow-listed URL parameters are `q` (2–80 characters), `category` (published slug), `sort`, `view`, `availability`, `discounted`, `featured`, repeated `diet`, repeated `excludeAllergen`, and `page`. Page size is 12 and the catalog window is capped at 10,000 records. Invalid or unknown category filters return a recoverable no-results state, never an unfiltered catalog. The default is available dishes in recommended grid order. All visible prices come from the authoritative pricing engine; the browser supplies no prices. Allergen filtering is only advisory, and the interface tells customers to contact the kitchen about allergies.

The page follows the supplied grid/list menu designs' banner → filter bar → dish cards → pagination hierarchy. Thumbnails use processed media variants when present, with a dimensioned placeholder otherwise. Category copy, controls, status text, and guidance are translated in English, Portuguese, and Persian. Native form controls, visible labels, keyboard-operable `<details>`, named pagination links, and a labelled view-mode group provide the accessible interaction baseline.

Verification includes parser bounds and URL-state unit tests, component tests for semantic controls/cards/no-results, a browser check for server-rendered HTML, automated accessibility, and mobile overflow, plus locale completeness, lint, typecheck, and production build. Production performance and final-content visual audits remain in launch verification.
