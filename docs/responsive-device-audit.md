The audit initially exposed a public-page server-rendering regression: four Server Components passed callback-valued MUI `sx` props across a client boundary. The About, Blog, Contact, and Menu banners now use serializable `sx` objects with a dark-scheme selector. This was required before route/viewport results could be trusted.

Blog routes also passed function-valued `component={Link}` into MUI client components. Those links now render as native anchors. This keeps the routes server-renderable, at the cost of full-page navigation for those specific blog links.

Verification: all four focused Playwright tests passed after the fixes. The dark-public-page contrast regression check, production build, TypeScript, and targeted ESLint also passed.

To close SK-0184, repeat the critical storefront, cart/checkout, profile, and authorized dashboard paths on current Safari/iOS and Chrome/Android devices; check portrait/landscape rotation, actual browser zoom, touch target spacing, and on-screen keyboard behavior. Record device/OS/browser versions and any defects. The automated viewport and simulated-keyboard results do not establish those physical-device outcomes.
